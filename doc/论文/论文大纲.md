# 论文大纲

> 创建于 2026-08-29，主题：科研、论文

## Research Plan Summary
### 题目
面向资源受限RTOS FPGA SoC的帧级3D场景卸载架构与软硬件划分评估

### 研究问题

在资源受限的 RTOS FPGA SoC、等价低模工作负载下，帧级场景卸载能否比单纯矩阵运算卸载释放更多可调度 CPU 时间，同时维持实时帧预算并控制硬件资源代价？

### 方法方向

三级同平台对照：

1. CPU 完成全部几何处理；
2. 矩阵乘法器仅卸载顶点变换；
3. Scene Controller 完成变换、构面、剔除与 Painter，CPU仅提交帧命令。

统一定点格式、LUT、剔除、排序和 RGB332 输出，并保留三角形命令序列及 framebuffer CRC 作为运行诊断。软件基线按变换、构面/剔除、Painter、命令提交分段计时。

### 证据策略

- 主指标：CPU active cycles/frame。
- 约束指标：P99 帧延迟与33.3 ms实时预算。
- 支持指标：RT-Thread空闲率、后台任务吞吐。
- 预设成立条件：相对矩阵乘法器方案，CPU周期下降≥30%，P99延迟增幅≤10%且不突破实时预算。
- RTL仿真扫描V/T/M模型族；上板采用轻载、中载拐点、满载三个点，300帧×5次。
- Scene Command FIFO扩至32项，并公开资源与Fmax代价。

### 已知局限

结论限定于正交投影、Painter、RGB332、128V/192T/1Mesh以内的无纹理低模场景。主要内部有效性风险是软件基线优化不足、输出不等价和CPU计时口径不公平。

### 预期贡献

建立“CPU可调度时间—帧延迟—硬件资源”三维权衡，用于带低模3D状态可视化的机器人或交互终端，使CPU保留时间承担RT-Thread GUI、输入、控制与通信。

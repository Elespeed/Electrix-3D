# T00 交接：共享 3D 资产迁移

## 目标

把所有可被生成器、单元仿真、SoC 仿真和软件共用的 3D 模型资产迁到仓库根目录 `assets/3d/`，使 `tools/3d_gen/` 只保留工具，`sim/test/sketch/3d/` 和 `sim/test/sketch_soc/` 只保留测试代码。

## 允许修改范围

- `assets/3d/`
- `tools/3d_gen/`
- `sim/test/sketch/3d/`
- `sim/test/sketch_soc/`
- 与上述 TB 对应的 `fpga/verilator/filelist/`
- `sdk/software/examples/sk_os/` 中仅限 br01 catalog 常量接入
- `.gitignore`
- 路径相关文档

不得修改 RTL 功能、模型格式、渲染算法、软件业务逻辑或任何 `FRAME_DUMP_LIMIT(0)`。不得提交或推送；总控 agent 验收后统一处理 Git。

## 目标目录

```text
assets/3d/
├─ sources/<asset>/                 # OBJ、MTL、pivot、V4 描述等人工源文件
├─ generated/<asset>/v3|v4/        # JSON、MIF、BIN、SVH 确定性产物
├─ packages/br01/                  # JSON、s3dpkg MIF/BIN、catalog header
├─ fixtures/                       # 手写且非生成的测试夹具
└─ previews/                       # PNG/GIF/summary，默认忽略
```

## 实施要求

1. 用 `git mv` 保留已跟踪资产历史；不保留软链接、目录副本或兼容镜像。
2. 将 `tools/3d_gen/Makefile` 默认根改为新目录，但保留 `MODEL_ROOT`/`ASSET_ROOT`/`FRAME_ROOT` 命令行覆盖能力。
3. 更新 `robotss_walk.py`、生成器/渲染器单测及工具 README 的默认路径。
4. 更新所有 TB 的资产路径，保留 ModelSim 从 `fpga/modelsim/build` 和 Verilator 从 `fpga/verilator` 运行时的双相对路径。
5. 修正 `sketch_blade_3d_tb.sv` ModelSim 分支误读 cat 资产的旧问题，并为 `sketch_scene_soc_tb.sv` 补齐双路径。
6. br01 包生成稳定的 catalog header；`sk_os` 从该 header 取模型编号，不再手写 0/1/2。
7. 先按现有 TB 实际消费映射迁移 legacy 顶层产物，不得因同名就删除；重生成后必须做 byte/hash 审计。
8. 新增 `assets/3d/manifest.json`，记录 asset id、版本、V/T/M、生成命令、相对路径与 SHA-256。
9. 全仓有效代码与文档不得再引用 `sim/test/sketch/3d/assets`、`sim/test/sketch/3d/model` 或 `tools/3d_gen/frame`。

## 验收命令

```powershell
python -m unittest discover -s tools/3d_gen/tests -v
make -f tools/3d_gen/Makefile ASSET=blade convert
make -f tools/3d_gen/Makefile ASSET=robotss convert
make -f tools/3d_gen/Makefile package-br01
```

需另加机械校验：MIF/BIN 按 32-bit little-endian word 等价；br01 JSON 的 offset/size/CRC/模型编号与包和 header 一致；旧路径 `rg` 检查为零。

```powershell
make -C fpga/verilator TB=sketch_model_3d_tb run-batch
make -C fpga/verilator TB=scene_sk_catalog_switch_tb run-batch
make -C fpga/verilator TB=scene_sk_multimesh_walk_tb run-batch
make -C fpga/verilator TB=sketch_soc_os_3d_demo_tb run-batch
make -C fpga/verilator TB=sketch_soc_os_robot_walk_tb run-batch
```

## 返回格式

- 修改文件与迁移统计
- 每条验收命令的 PASS/FAIL 和首个有意义错误
- 旧路径残留列表
- 未解决风险与建议的下一最小动作
- `git diff --stat`

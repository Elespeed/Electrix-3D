# 核心架构与流程

## SoC 架构

- RTL: `rtl/soc_top_sketch.sv`
- 结构: CPU → sketch_book_axi → 内嵌 BRAM → RGB332 DVI
- SketchBook MMIO 基址: `0xbf100000`
- SDK 配置: `CONFIG_PROFILE=remote`（默认）
- 命令模式: 默认开启 AUTO_PRESENT 和 ANIMATION

## 3D 模型生成流程

```
Blender OBJ/MTL → Python 导入/归一化 → 通用 3D 二进制 → ExtRAM → 通用 scene core → SketchBook TRIANGLE_FLAT → DVI
```

### 生成模型文件

```bash
# 基础生成（面着色效果）
make -f tools/3d_gen/Makefile ASSET=plane

# 等比缩放
make -f tools/3d_gen/Makefile ASSET=plane SCALE=0.4
```

输出位置: `sim/test/sketch/3d/assets/模型名/v3`

### Python 渲染模式

- `no_zbuffer`: 无深度缓冲
- `zbuffer`: 深度缓冲
- `zbuffer_object_outline`: 描边模式

## 软件构建

### SketchBook Demo

```bash
cd sdk/software/examples/sketchbook_demo && make clean && make CONFIG_PROFILE=remote
```

输出: `sdk/axi_ram.mif`

### OS 系统（中断控制动画）

```bash
cd sdk/software/examples/sk_os && make clean && make CONFIG_PROFILE=remote
```

功能:
- UI 主页（黄色光标选中卡片）
- 上下按键移动光标
- SW0 拨动进入/退出卡片
- 第一个应用: 3D 软件（btn3 切换模型，机器人行走）

## Blender 资源

- 源文件位置: `assets/3d/sources/`
- 导出格式: OBJ（顶点+三角形）、MTL（颜色）、JSON（Pivot）

## 动作功能

```bash
# 机器人行走渲染
python tools/3d_gen/robotss_articulation/robotss_walk.py --verify-neutral

# 侧视效果（30度偏航）
python tools/3d_gen/robotss_articulation/robotss_walk.py --yaw-degrees 30 --output assets/3d/previews/robotss/articulation/out_side30
```

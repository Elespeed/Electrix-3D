# 二阶段进度

## Scene Controller 测试与数据体系（2026-09-05）

- 已建立 `experiments/3d_scene/`：S0--S4 确定性 SK3D 资产生成、实验配置、运行目录、JSONL 校验、黄金 CRC 检查、统计脚本及 Makefile 入口。
- `rt_3d` 已支持 `RT3D_MODEL=S0..S4`；逐帧输出 Scene 性能计数器、CPU active/polling/blocked/wall、帧延迟和 RTOS 指标。Scene IRQ 等待区间已计入 `blocked_cycles`。

- 验证：S0 RT-Thread 镜像 WSL 交叉编译通过；`rt_3d_soc_tb` Verilator PASS（IRQ→CPU→semaphore、Scene 计数器和 DVI 输出均通过）。
